# Contributing to LEDGERLENS

LEDGERLENS is a baseline anomaly-detection prototype prepared for a coding event.

## How to contribute

1. Pick an open issue.
2. Understand the current baseline before changing it.
3. Make changes on a branch when possible.
4. Keep evaluation data separate from model development.
5. Compare your results with the baseline.
6. Explain what changed and why.

## For ML improvements

Please report the evaluation approach, anomaly-rate changes, examples of improved cases, and a short explanation of the method.

Avoid leaking evaluation information into model development.
